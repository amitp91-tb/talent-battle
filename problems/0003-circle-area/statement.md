# Area of a Circle

Given the radius R (a decimal), print the area of the circle: π · R².
Answers within 0.001 of the correct value are accepted (floating-point judging).

### Input
A single decimal R (0 < R ≤ 10^4).

### Output
The area. Any answer within 0.001 absolute error is accepted.

### Example
Input: `1` → Output: `3.14159` (3.141592653... also accepted)
