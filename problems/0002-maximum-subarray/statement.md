# Maximum Subarray Sum

Given an array of N integers, find the largest possible sum of any **contiguous**
non-empty subarray. (Classic Kadane's algorithm problem.)

### Input
Line 1: integer N (1 ≤ N ≤ 10^5)
Line 2: N space-separated integers (−10^4 ≤ each ≤ 10^4)

### Output
A single integer: the maximum contiguous subarray sum.

### Example
Input:
```
9
-2 1 -3 4 -1 2 1 -5 4
```
Output: `6`   (the subarray [4, -1, 2, 1])
